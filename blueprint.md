# **App Name**: Phone Doctor AI

## Core Features:

- Intelligent Health Dashboard: A centralized UI displaying real-time metrics for RAM usage, storage availability, and battery status using professional high-contrast cards.
- System Metric Integration: Integration with browser-based device memory and battery status APIs to provide accurate hardware data visualizations.
- Hindi AI Diagnosis Tool: A feature that uses a generative AI tool to analyze current device metrics and provide natural language health assessments in Hindi.
- Command Navigation Menu: A modern three-dot top-right corner menu to toggle between the main diagnostic views and the developer information page.
- Device Identity Module: A section providing detailed hardware identification including model, OS version, and processor architecture.
- Author Attribution View: A dedicated page showing developer credits for Tarun Joshi with a clean, minimalist typography layout.

## Style Guidelines:

- Primary Color: Deep Medical Blue (#0EA5E9) symbolizing professional diagnostic trust and technical precision.
- Background Color: Sophisticated Dark Slate (#0F172A) for high contrast and readability in the default dark theme.
- Accent Color: Indigo Bright (#6366F1) for subtle highlights on active hardware status indicators.
- Body and Headline font: 'Inter', a grotesque-style sans-serif for a neutral, machined, and highly objective diagnostic feel.
- Large, stroke-based architectural icons with consistent 2px weights to represent battery, memory, and storage categories.
- Spacious card-based bento grid layout featuring large touch targets and generous padding for an mobile-first feel.
- Subtle status pulse animations for system health cards to indicate active real-time data fetching.
